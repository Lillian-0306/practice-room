彈唱練習室

選一邊開始。每個練習都能直接發出聲音、跟著做，不用另外裝東西。

和弦圖與試聽

點選和弦，看按法，再聽聽正確的聲音是什麼樣子。

C

  • 圖中數字是左手手指：1 食指、2 中指、3 無名指、4 小指。
  • X 代表不彈，O 代表空弦。
  • 每條弦逐一彈，有悶音就調整手指位置。

標準調音

點每條弦聽標準音，轉旋鈕讓自己的吉他對上它。

由粗到細：6 弦 E、5 弦 A、4 弦 D、3 弦 G、2 弦 B、1 弦 E。

跟著節拍換和弦

每小節換一個和弦，節奏圖亮起時刷弦。

—
按開始
建議從 60–70 BPM 開始，穩了再加速。

吉他入門路線

完成就打勾，進度會存在這個瀏覽器。

    呼吸練習

    跟著圓圈吸氣、停住、吐氣。吸氣時肚子往外推，肩膀保持放鬆。

    準備—
    已完成 0 輪

    音高偵測器

    用麥克風聽你唱的音，顯示音名和偏高偏低多少。

    —
    按下開始，唱一個長音「啊」
    偏低準偏高

    參考音跟唱（不需要麥克風）

    點一個音，用「啊」唱出來，再和它比對是否一致。

    聽音辨唱名

    點琴鍵聽聲音。按「出題」會先給你 Do，再播一個音，請選出它是哪一個唱名。

    每日暖聲清單

    由簡到難，每天花 10–15 分鐘。

      • 感覺喉嚨緊或痛就停下來喝水休息。
      • 先唱小聲、音域中間的位置，再慢慢擴大。
      聲音皆由瀏覽器即時合成。戴耳機效果更好。
